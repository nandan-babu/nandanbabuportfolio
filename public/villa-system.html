Villa System - Real Estate Management

Developed a full-stack real estate management system for property listings, bookings, and builder approvals. Implemented three role-based modules (Admin, Builder, User) with dedicated dashboards. Built using Python Django, MySQL, and Django REST Framework, featuring a responsive frontend built with HTML, CSS, JavaScript, and Bootstrap.

User Functionality: Users can browse available properties, view detailed listings, instantly book a property, or schedule a meeting directly with the builder to finalize details.

Builder Functionality: Builders can register, add new properties to the platform, and monitor their dashboard to track the status of meetings (ongoing, pending, closed) and latest bookings.

Admin Functionality: Administrators have full oversight, including approving or removing user and builder accounts, managing property listings, and maintaining platform integrity.
