MediPlus – Doctor Appointment Management System

The MediPlus application is a web-based doctor appointment management system developed to connect users with doctors and simplify the process of finding doctors, scheduling meetings, and tracking appointment activities. The system has three main modules: Admin, User, and Doctor, each with specific functionalities.

1. Admin Module

  • Approves or rejects registration requests from users and doctors.
  • Monitors the total number of scheduled appointments and meetings.
  • Tracks how many doctors each user has visited.
  • Manages and monitors overall system activity through the admin dashboard.

2. User Module

  • Registers and logs in to the application after account approval.
  • Searches and views doctors based on their medical specialties and associated hospitals.
  • Schedules meetings or appointments with selected doctors.
  • Views and manages personal profile details and password settings.
  • Tracks appointment history and views the number of doctors visited.

3. Doctor Module

  • Registers and logs in after admin approval.
  • Views upcoming, completed, and ongoing appointments.
  • Monitors the number of meetings conducted with different users.
  • Views appointment details and tracks interactions with users.

Overall Purpose: MediPlus centralizes doctor discovery and appointment scheduling in a single platform. It helps users find suitable doctors, enables doctors to manage their appointment schedules, and allows administrators to monitor registrations, appointments, and system activity efficiently.
